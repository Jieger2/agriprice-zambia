# AgriPrice Zambia

**Cloud-native agricultural market intelligence for Zambian smallholder farmers, built for feature phones and 2G.**

Farmers dial a USSD code (or send `PRICE MAIZE` by SMS) to get the current price at the three markets nearest them, list crops for sale, and set price alerts. Buyers post demand and are matched to nearby supply. Extension officers register farmers and submit field prices. Price data is ingested on a schedule, normalised, stored in a data lake and turned into seasonal trends and forecasts.

Cloud Application Development mini-project, ZUCTECH. Design rationale: the project thesis (*AgriPrice Zambia: Design of a Cloud-Native, Low-Bandwidth Agricultural Market Intelligence Platform*).

```
Feature phone ─USSD/SMS─> Africa's Talking ─> API Gateway ─> ① USSD/SMS Gateway ─┐
Web (2G PWA) ─> CloudFront ─┬─> API Gateway + Cognito ─> ② Farmer & Listings API ─┼─> DynamoDB (geohash keys, TTL sessions)
                            └─> API Gateway ─────────> ⑥ Analytics API ───────────┤      │
EventBridge schedule ─> ③ Ingestion ─> S3 raw ─(Athena INSERT)─> S3 Parquet ─────┘      │
        │  └─> SQS price-normalised ─> ⑤ Alerts ─> SMS                                    │
        └ ② ─> EventBridge bus ─> SQS match-requests ─> ④ Matching ─> SMS                 │
All six Lambda services run in private subnets across two Availability Zones ─────────────┘
```

## What is in the repository

| Path | Purpose |
|---|---|
| `services/<name>/` | Six independently deployable services, each with its own SAM template, IAM role, alarms and log group |
| `shared/agricommon/` | Shared domain library (geohash, byte-budget encoders, GSM-7 text, i18n, DynamoDB access, SMS client), packaged as a Lambda layer **inside each stack** so services stay independent |
| `infra/` | `bootstrap` (GitHub OIDC + deploy roles), `network` (2-AZ VPC, NAT instance), `data` (DynamoDB, S3, Glue/Athena, SQS, EventBridge, Cognito, CloudTrail), `web` (CloudFront + S3), `observability` (dashboard), `budget` |
| `web/` | 2G-friendly progressive web app (~45 KB in total, no framework, offline outbox) |
| `tests/unit/` | 105 unit tests with moto, about 96% coverage (CI gate: 60%) |
| `tests/smoke/` | Post-deploy smoke tests |
| `load/` | k6 load tests for the auto-scaling and latency demonstrations |
| `scripts/` | `deploy.py` (cross-platform deploy), `local_server.py` (run everything locally), `ussd_cli.py` (phone simulator), `make_sample_data.py` |
| `docs/` | **Stakeholders and use cases (`use-cases.md`)**, architecture, security and IAM justification, SLOs, runbooks, cost, demo script |

## Run it locally (no AWS account needed)

Use Python 3.12 or 3.13.

```bash
pip install -r requirements-dev.txt
pytest --cov                                  # unit tests + coverage
python scripts/local_server.py                # http://localhost:8080 and http://localhost:8080/simulator.html
```

The real Lambda handlers serve every request. Production services are replaced by local stand-ins:

| Production | Locally |
|---|---|
| DynamoDB, S3, SQS, EventBridge, Cognito | moto, in memory |
| SQS → Matching / Alerts event source mappings | background pumps sending the same SQS events to the same handlers |
| Athena `INSERT INTO` + nightly aggregation | in-process curated table and the same aggregation in Python |
| Africa's Talking USSD | **phone simulator** page (`/simulator.html`) or `python scripts/ussd_cli.py` |
| Africa's Talking SMS | SMS **outbox**, shown in the simulator's inbox (`SMS_MODE=outbox`) |
| Cognito hosted UI | **Sign in** role picker: Buyer, Extension officer or Administrator |
| Open-Meteo weather | deterministic mock rainfall per province (`WEATHER_MODE=mock`) |

**Pages:**
- **Prices:** delta-synced, works offline.
- **Trends:** seasonal chart, a 4-week forecast with the weather adjustment, and the seasonal index.
- **Buy:** post demand, see matched sellers for each demand, and search nearby supply.
- **Officer:** regional dashboard, register farmers, list crops with unit and available-from date, and field price reports.
- **Admin:** markets, crops and unit conversions; price sources with a "run ingestion now" button; and users and roles.

The local server ingests the bundled **synthetic** sample prices (`data/zambia_sample_prices.csv`, generated by `scripts/make_sample_data.py`). They are not real market observations; see [Price data](#price-data).

## Deploy to AWS

Requirements: Python 3.12, [AWS SAM CLI](https://docs.aws.amazon.com/serverless-application-model/latest/developerguide/install-sam-cli.html), and AWS credentials for a standalone account. The default Region is `eu-north-1` (Stockholm), which is enabled on every account. To use another Region, set `AWS_REGION` locally and the repository variable `AWS_REGION` for CI. For example, use `af-south-1` (Cape Town) once it has been opted in under *Account → AWS Regions*; nothing else changes.

```bash
python scripts/deploy.py doctor               # checks SAM CLI, AWS CLI, credentials and Region
python scripts/deploy.py bootstrap            # once per account: OIDC role for GitHub, artifacts bucket, $20 budget
python scripts/deploy.py deploy --env dev     # network → data → 6 services → web → dashboard
python scripts/deploy.py run-pipeline --env dev   # first ingestion + analytics refresh
python scripts/deploy.py outputs --env dev    # web URL, USSD callback URL, dashboard link
python scripts/deploy.py add-user --env dev --email you@example.com --role admins   # first administrator
```

**Accounts from AWS's new sign-up experience** (Sept 2026 onwards) carry AWS-managed service control policies that block IAM OpenID Connect. `bootstrap` detects this, skips the GitHub Actions deploy role and continues; deploy from a laptop with `deploy.py`. To restore GitHub deployments, activate advanced features in AWS Settings (irreversible; requires the Paid Plan).

Each stack is deployed in dependency order, and a marker can do the same in a clean account from this repository. To redeploy one service only: `python scripts/deploy.py deploy --env dev --only matching`.

### Continuous delivery

`.github/workflows/ci.yml` runs on every push and pull request:

1. lint (`ruff`, `cfn-lint`)
2. gitleaks secret scan over the full history
3. Checkov IaC security scan
4. unit tests with a 60% coverage gate
5. deploy to dev, then smoke tests
6. deploy to prod with a **10% canary for 5 minutes and automatic rollback** on alarms

The deploy jobs run only after you add the repository variable `AWS_DEPLOY_ROLE_ARN` (printed by `bootstrap`). Until then CI still lints, scans and tests. No AWS keys are ever stored in GitHub.

### Africa's Talking (USSD and SMS)

1. Create a free sandbox account and app at africastalking.com.
2. Store the key: `AT_API_KEY=... python scripts/deploy.py deploy --env dev --sms-mode sandbox`.
3. In the sandbox, create a USSD channel and set its callback to the `ussd_callback` URL from `outputs`, which includes `?k=<token>`. Set the SMS callback the same way.
4. Test from the Africa's Talking simulator.

Without a key, deployments use `SMS_MODE=outbox`: messages are stored instead of sent, at no cost. Read them with `python scripts/sms_outbox.py --env dev --phone 0977123456`.

### Price data

The `seed` source loads the synthetic CSV so every feature can be demonstrated. For real prices, set `WFP_CSV_URL` (a GitHub repository variable, or an environment variable for local deploys) to the download link of the *Zambia – Food Prices* CSV on the Humanitarian Data Exchange (WFP dataset). Officers' field reports form the third source.

## Key design decisions

- **Serverless instead of containers.** There is no idle cost, and Lambda satisfies "≥3 independently deployable services". See `docs/architecture.md`.
- **SQS and EventBridge instead of Kinesis.** Both are explicitly allowed by the brief, and Kinesis bills per shard-hour even when idle.
- **Athena `INSERT INTO` as the ETL step instead of Glue jobs.** Glue Catalog tables are declared in IaC, so no crawlers are needed.
- **A NAT instance (t4g.micro, Amazon Linux 2023, fck-nat style) instead of NAT Gateways.** This saves about $63 a month, and S3 and DynamoDB traffic goes through free gateway endpoints.
- **Every byte justified.** USSD screens are capped at 182 characters and SMS at 160 GSM-7 characters, both enforced by contract tests. A compact price record is 48 bytes, compared with 175 bytes as verbose JSON. Responses use ETag/304, and the web app needs no chart library.
- **Privacy.** Phone numbers are pseudonymised with a keyed hash in keys and logs. Farmers can text `STOP` to delete their profile (Zambia Data Protection Act No. 3 of 2021).
